# ✨ Aether Gallery

An interactive, modern image gallery web application featuring a cinematic lightbox view, dynamic category filtering, smooth animations, and full keyboard support.

![Project Demo]( https://chaithanya8861.github.io/CodeAlpha_ImgageGallery/)

## 🌟 Live Demo

Experience the gallery live right here: **[https://chaithanya8861.github.io/CodeAlpha_ImgageGallery/]( https://chaithanya8861.github.io/CodeAlpha_ImgageGallery/)**

## ✨ Key Features

- **🎨 Dynamic Category Filtering** – Seamlessly browse images by categories: Nature, Urban, Abstract, and Portrait.
- **🖼️ Cinematic Lightbox** – Click any image to open a full-screen lightbox with smooth transitions.
- **📱 Fully Responsive** – Enjoy a perfect layout on desktops, tablets, and mobile devices.
- **⌨️ Keyboard Navigation** – Use the arrow keys (`←` `→`) to navigate between images and `ESC` to close the lightbox.
- **✨ Hover Effects** – Each image features elegant scale and brightness transitions on hover.
- **🎭 CSS Image Filters** – Subtle vintage and cool-tone filters apply on hover for an enhanced visual experience.

## 🛠️ Technologies Used

- **HTML5** – Semantic markup for structure and accessibility.
- **CSS3** – Modern styling with Flexbox, Grid, gradients, and CSS animations.
- **Vanilla JavaScript** – Handles all interactivity: filtering, lightbox logic, and keyboard events.

## 🚀 How to Use

1.  **Browse the Gallery** – Scroll through the responsive grid of images.
2.  **Filter Images** – Click on any category pill (e.g., "Nature", "Urban") to view only images from that group.
3.  **Open Lightbox** – Click on any image to open it in the full-screen lightbox viewer.
4.  **Navigate** – Within the lightbox, click the **‹** and **›** buttons or use your keyboard's **left** and **right** arrow keys.
5.  **Close Lightbox** – Click the **✕ (X)** button, click outside the image, or press the **`ESC`** key.
